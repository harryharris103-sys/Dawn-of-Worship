V1.1.0 Changes
Repair of .pptx compatibility.
Enhanced compatibility of other .json bible versions
Ability to access suitable files in the GitHub repo
Other Bible JSON formats now work. Your KJV and ASV files use a different schema ({metadata, verses: [{book_name, chapter, verse, text}]}) than the NIV file. The importer now recognizes both formats automatically, and it even pulls the proper version name ("KJV", "ASV") straight from the file's own metadata instead of guessing from the filename.
PPTX now shows the actual slide layout, not just plain text. Each text box keeps its original position, size, color, and bold styling; embedded images and slide backgrounds are carried over too. What still won't transfer: charts, SmartArt, tables, animations, and embedded custom fonts — those are genuinely hard to replicate outside PowerPoint itself, so text and images is where this realistically tops out.
3. GitHub folder auto-sync. There's a new 🔄 button in the header. It reads your repo folder's file listing (via the GitHub API) and automatically imports any .json Bible, image/video, .pptx, or .txt lyric file it finds sitting alongside index.html — no manual per-file import needed anymore. It runs once automatically on load, and skips anything already imported, so it stays fast. Click it manually anytime after adding new files to the repo to pull them in without a full re-import. (This only works once actually hosted on *.github.io — it's a no-op if you're just opening the file locally.)
